# 冷檬数据仪表盘制作 Skill

把一份**已清洗的业务数据表**（Excel / CSV / 飞书多维表格 / 在线文档）加上一份**分析报告**，做成一块开会投屏直接能用的交互式 HTML 仪表盘。

> 一句话：给它表和结论，它给你一块能上墙的盘。

## 它解决什么问题

| 常见做法 | 做出来的东西 |
| --- | --- |
| 把 Excel 图表截图贴进 PPT | 分辨率糊、投屏看不清、改一个数要重做 |
| 用 BI 工具 | 要先建模、配数据源，汇报前改口径来不及 |
| 用本 Skill | 读表 + 读报告 → 挖重点 → 定图表和风格 → 出**单文件 HTML**，离线打开、投屏可读、改 spec 重跑 30 秒出新版 |

## 核心特点

- **五块交付**：读材料摘要 → 重点数据候选清单 → 图表类型 + 2–3 套美化风格 → 一句话结构确认 → 成品 HTML + 使用说明。
- **输入不卡死**：表+报告最理想；只有表、只有报告、只有原始表，都有对应备选分支，并明确提示缺口。
- **五种图表**：折线、柱形、横向条形、环形占比、转化漏斗，由数据特征定，不把选型甩给用户。
- **四套风格**：沉稳蓝橙 / 墨绿金 / 石墨紫灰 / 素灰单色，每套含配色、字号层级、留白、文案口吻与适合场景。
- **零依赖**：模板纯 HTML + 原生 JS + SVG，不引任何 CDN，断网、内网、离线笔记本都能开。
- **可校验**：生成脚本会检查类别与数据长度、环形图 ≤5 类、漏斗逐层递减、主题名、KPI 数量，出错指到字段路径。
- **有纪律**：不重算统计、不编造数据、不假设口径、不编造报告结论；在线表联动只在拿到可访问链接时做，否则标注「数据快照」。

## 触发方式

直接说人话即可：

- 「把这张表做成仪表盘，开会要投屏」
- 「做个经营看板，突出营收趋势和区域排名」
- 「冷檬仪表盘：这份月报 + 这张数据表，做个汇报大屏」

## 使用流程

1. **给材料**：数据表 + 分析报告（Word/飞书文档）。缺一样也能做，会走备选方案。
2. **勾重点**：它列 5–6 类值得上墙的数据（KPI 卡 / 趋势 / 排名 / 占比 / 漏斗 / 异常），你勾选。
3. **挑风格**：它按数据特征定图表类型，再给 2–3 套完整美化方案，你挑一套或混搭。
4. **确认结构**：一句话确认「顶部几张 KPI 卡、中部什么图、用哪套风格」。
5. **拿成品**：单文件 HTML，双击打开；要改就改 `spec.json` 重跑脚本。

## 设计依据

不是凭手感调样式，几条原则写死在流程里：

- **预注意属性**（认知心理学）：颜色、大小、位置先行，最重要的数字放大、上色、放最左。
- **数据墨水比**（Tufte）：删网格线、去阴影渐变，笔墨只留给数据。
- **结论先行**（金字塔原理）：标题即观点，「营收同比增长 23%」而不是「各月营收」。
- **色盲安全**：禁红绿对比，用蓝橙 / 蓝紫；好消息坏消息靠符号冗余，不只靠颜色。
- **渐进式披露**：KPI 卡给结论，图表给细节，一屏不过载。

## 边界与限制

- 不替你重算指标。表里没算的，需要你授权后才统计。
- 数据必须是材料里真实存在的，缺字段会说缺，不补脑。
- 在线表格联动需要可访问的链接/接口；拿不到就生成快照并明确标注。
- 目前图表类型为折线、柱形、条形、环形、漏斗五种，散点/地图未内置。
